중립 기본형 UI 킷

시안·프로토타입·보고용 페이지를 만들 때 가져다 쓰는 기본 재료다. 특정 회사 색이 들어 있지 않아 사내·사외 어디에 올려도 문제가 없다. 보이는 화면이 곧 이 킷으로 그려져 있다.

v1.0 · 2026-08-19 · 라이트/다크 자동 대응

시작하기

쓰는 법은 둘 중 하나다. 통째로 가져가거나, 필요한 조각만 복사한다.

통째로 쓸 때 아래 토큰 전체를 새 파일 맨 위에 붙이고, 각 조각의 클래스 이름(k-btn, k-card …)을 그대로 쓴다.

조각만 쓸 때는 각 예시 아래 코드를 복사한다. 코드에 쓰인 var(--…) 값이 토큰이므로, 토큰 목록도 함께 가져가야 색과 간격이 맞는다.

색

색에 이름을 붙여 정해둔 목록이다. #2f6f5e 대신 var(--accent)로 부르면, 다크 모드에서 알아서 다른 값으로 바뀐다. 강조색은 하나만 둔다 — 여러 개를 쓰면 무엇이 중요한지 안 보인다.

지면과 글자

--paper페이지 바닥
--surface카드·입력칸
--surface-2한 단계 눌린 면
--line테두리
--ink본문 글자
--ink-2보조 설명
--ink-3라벨·주석
--ink-4비활성

강조와 상태

--accent강조 — 딱 하나
--accent-soft강조 배경
--good정상·완료
--warn주의
--bad오류

상태 3색은 강조색과 별개다. 「좋다·주의·나쁘다」를 나타낼 때만 쓰고, 예쁘게 보이려고 쓰지 않는다.

타이포

글자 크기를 미리 8단으로 정해뒀다. 매번 정하지 않고 이 중에서 고른다. 본문 글줄은 65자 안쪽으로 끊는다 — 그보다 길면 눈이 다음 줄을 못 찾는다.

display · 32/700참여형 광고 리드폼
h1 · 24/700캠페인 성과 요약
h2 · 19/600응답 결과 보고서
h3 · 16/600문항별 응답 분포
body · 15/400본문이다. 줄간격 1.65로 두면 한글이 답답해 보이지 않는다.
small · 13/400보조 설명이나 각주에 쓴다.
label · 11/600지표 라벨
mono · 131,204,873 · MA-1120

글꼴은 IBM Plex Sans KR(본문)과 IBM Plex Mono(숫자·코드) 두 벌이다. 숫자가 세로로 늘어서는 표에는 font-variant-numeric: tabular-nums를 준다.

<link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+KR:wght@400;500;600;700&family=IBM+Plex+Mono:wght@400;500&display=swap" rel="stylesheet">

--font: "IBM Plex Sans KR", -apple-system, "Malgun Gothic", sans-serif;
--mono: "IBM Plex Mono", ui-monospace, Consolas, monospace;

컴포넌트

자주 쓰는 조각이다. 버튼 하나를 매번 새로 만들면 페이지마다 높이가 달라진다. 여기 있는 것을 먼저 찾고, 없을 때만 새로 만든다.

버튼

한 화면에 k-btn(채운 버튼)은 하나만 둔다. 그게 「지금 눌러야 할 것」이다.

<button class="k-btn">신청하기</button>
<button class="k-btn k-btn--outline">취소</button>
<button class="k-btn k-btn--ghost">나중에</button>
<button class="k-btn k-btn--sm">작은 버튼</button>

입력칸

실명으로 입력해 주세요.
번호 11자리를 모두 입력해 주세요.

오류 문구는 무엇이 잘못됐고 어떻게 고치는지를 쓴다. 「잘못된 값입니다」로 끝내지 않는다.

<div class="k-field">
  <label for="name">이름</label>
  <input class="k-input" id="name" placeholder="홍길동">
  <span class="k-help">실명으로 입력해 주세요.</span>
</div>

토큰 전체

새 파일을 만들 때 이 덩어리를 맨 위에 붙인다. 라이트·다크 세 가지 상태를 모두 처리한다 — 시스템 설정을 따르는 기본 상태까지 포함이다.

:root {
  --paper:#fbfbfa; --surface:#ffffff; --surface-2:#f3f3f1;
  --line:#e3e3e0; --line-soft:#eeeeec;
  --ink:#1a1c1e; --ink-2:#4a4f55; --ink-3:#767b81; --ink-4:#a3a8ad;
  --accent:#2f6f5e; --accent-ink:#ffffff; --accent-soft:#e9f2ef; --accent-line:#bcd8ce;
  --good:#2f7a4f; --warn:#a8701c; --bad:#b23a34;
  --good-soft:#eaf4ee; --warn-soft:#faf1e2; --bad-soft:#fbecea;
  --font:"IBM Plex Sans KR",-apple-system,"Malgun Gothic",sans-serif;
  --mono:"IBM Plex Mono",ui-monospace,Consolas,monospace;
  --s1:4px; --s2:8px; --s3:12px; --s4:16px; --s5:24px; --s6:32px; --s7:48px; --s8:72px;
  --r1:4px; --r2:8px; --r3:12px; --r4:20px;
  --shadow-1:0 1px 2px rgba(20,24,28,.06),0 1px 1px rgba(20,24,28,.04);
  --shadow-2:0 4px 16px rgba(20,24,28,.10);
  --shadow-3:0 12px 40px rgba(20,24,28,.18);
}
/* 시스템이 다크일 때 (사용자가 라이트를 명시하지 않은 경우) */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    --paper:#141618; --surface:#1b1e21; --surface-2:#23272a;
    --line:#2f3438; --line-soft:#262a2e;
    --ink:#e9eaec; --ink-2:#b6bbc0; --ink-3:#878d93; --ink-4:#616770;
    --accent:#5fbfa5; --accent-ink:#10201c; --accent-soft:#1c2f2a; --accent-line:#2f5b50;
    --good:#5db97f; --warn:#d5a55a; --bad:#e07a72;
    --good-soft:#1a2b21; --warn-soft:#2c2418; --bad-soft:#2e1e1d;
    --shadow-1:0 1px 2px rgba(0,0,0,.4);
    --shadow-2:0 4px 16px rgba(0,0,0,.5);
    --shadow-3:0 12px 40px rgba(0,0,0,.6);
  }
}
/* 사용자가 다크를 명시한 경우 */
:root[data-theme="dark"] { /* 위 다크 값과 동일하게 한 번 더 */ }

body { background: var(--paper); color: var(--ink); font-family: var(--font); }

마지막 줄이 중요하다. body에 배경을 명시하지 않으면 페이지가 뜨는 곳의 배경을 그대로 받아, 라이트 바탕에 라이트 글자가 나오는 사고가 난다.
